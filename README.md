# Réseau ENSAM Meknès

La plateforme des lauréats et des étudiants de l'ENSAM Meknès : offres de stage, de PFE et d'emploi, mentorat, entraide et messagerie.

**Site : https://reseau-ensam-meknes.github.io/**

Le site publié est à la racine de ce dépôt. Il est construit depuis [`source/`](source/README.md), et les tests automatiques vérifient à chaque changement que les deux correspondent.
